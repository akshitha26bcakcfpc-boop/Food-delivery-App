1. Project Overview

Food Delivery App – UI/UX Design

 “This project is a food delivery mobile application designed to make food ordering simple, fast and convenient. Users can browse restaurants, select food items, add them to cart, choose delivery address and payment method, and track their order.”

2. Objective

To create a simple and user-friendly food ordering app

To make the ordering process quick and easy

To provide clear navigation

To allow users to track their orders

To create a clean and attractive mobile interface


3. Features

🍔 Main Features:

Location selection

Food search

Food categories

Restaurant listing

Food details

Add to cart

Quantity selection

Delivery address

Multiple payment methods

Order tracking

Order delivered confirmation

Food rating

5. Typography

Font: Poppins / similar clean sans-serif font

Use:

Bold → Headings

Medium → Restaurant and food names

Regular → Descriptions and details


6. Design Highlights

Clean and simple layout

Orange used for buttons and important actions

White background for a clean appearance

Rounded cards and buttons

Food images to make the app attractive

Simple icons for easy navigation

Consistent spacing and alignment

Clear price and order information
